# KM Core & Decor

Modern interior design website built with React, Vite, and Tailwind CSS.

## Available scripts

- `npm install` — install dependencies
- `npm run dev` — start local dev server
- `npm run build` — build optimized production assets
- `npm run preview` — preview production build

## Notes

This project is scaffolded and ready. The local environment where the files were generated does not have Node.js / npm installed, so dependency installation must be run on your own machine.
